プライバシーポリシー

対象アプリ：NAS Reminders Sync（個人用）
更新日：2026年10月4日

アクセスと用途

所有者が選択したGoogle TasksとiCloudリマインダーのリストから、タイトル、メモ、日付、完了状態、項目ID、更新版などの同期に必要な情報を取得します。Googleのメールアドレスとアカウント識別情報は、同期先が設定した所有者であることの確認に使用します。対応可能な項目の作成・編集・完了状態の反映だけを行い、削除は実装していません。

保存

同期状態、対応付け、内容の基準値、未確定処理の記録、Google OAuth認証情報、Apple Webセッションを所有者のNASの専用フォルダーに保存します。通常のAppleパスワードは保存しません。項目のタイトルや認証情報を通常の稼働ログに出力しません。認証情報はOSのファイル権限でアクセスを制限します。

通信と共有

同期のため、選択した項目の対応可能な内容をGoogleとAppleの間でコピーします。通信先はGoogle Tasks API、Googleの認証・本人確認サービス、AppleのiCloudサービスです。Googleから取得したデータは、この同期とその検証以外に利用しません。広告、販売、外部の分析、AIモデルの学習・推論には利用しません。公開ページやそのホスティング先にタスクや認証情報を送信しません。

Google APIから受信した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

停止・保管期間・削除

NASの同期アプリを停止し、Googleアカウントの接続済みアプリからアクセスを取り消すと、Googleへの今後のアクセスを停止できます。NASに保存したApple Webセッションも削除できます。同期状態と認証情報は、所有者がNAS上から削除するまで保存します。停止や認証の取り消しだけでは、両サービスに作成済みのコピーは削除されません。

公開ページ

この説明ページに入力フォーム、アクセス解析、広告は設置していません。ページ配信元のGitHubによる通信情報の扱いはGitHubのプライバシーステートメントをご確認ください。アプリの問い合わせ先はGoogle OAuth同意画面のサポート連絡先です。公開の場にタスクや認証情報を投稿しないでください。
